## What I Actually Build

> Not tutorials. Not clones. Things I had to figure out from scratch.

<br/>

### AI Code Editor — Two Versions
**Web:** `Next.js 16` &nbsp;|&nbsp; **Desktop:** `React + Tauri + Rust` &nbsp;|&nbsp; **Brain:** `DeepSeek R1`

Built a fully working AI code editor without using any IDE framework. The DeepSeek R1 inference pipeline, streaming tokenizer, and context window management are all written by hand. No wrapper libraries. Multi-file chat, inline completions, syntax highlighting, file explorer, embedded terminal — all from scratch. Then I shipped it in two forms: a web app and a native desktop app sharing the same core.

---

### DeepSeek R1 from Scratch
`PyTorch` &nbsp;|&nbsp; `CUDA` &nbsp;|&nbsp; `Python`

Reproduced the full DeepSeek R1 architecture in raw PyTorch. Mixture-of-experts routing, RoPE positional embeddings, grouped-query attention — every module came from reading the paper and translating math to tensors. No Hugging Face model classes. Got it running on a single student GPU by profiling memory carefully.

---

### Autonomous Deep Research Agent
`LangGraph` &nbsp;|&nbsp; `LangChain` &nbsp;|&nbsp; `RAG` &nbsp;|&nbsp; `FastAPI` &nbsp;|&nbsp; `PostgreSQL`

Multi-agent system where specialized LLM workers plan, search, synthesize, and fact-check independently before a final report gets assembled — no human involvement mid-run. Agents retrieve from a private vector store so output stays grounded in actual sources. Each agent critiques its own draft against retrieved documents and rewrites before passing downstream. Streaming FastAPI backend feeds a React frontend so you watch each agent reason in real time.

---

### Fretron — Freight Logistics Platform
`Next.js` &nbsp;|&nbsp; `Node.js` &nbsp;|&nbsp; `PostgreSQL` &nbsp;|&nbsp; `Three.js` &nbsp;|&nbsp; `GSAP`

Shippers post loads, carriers bid in real time, both sides manage contracts in a shared dashboard. The landing page runs Three.js with custom GLSL shaders and GSAP ScrollTrigger sequences — targeting Awwwards-level quality. Covered the full engineering lifecycle from user research through UML artifacts to sprint delivery.

---

### Freight Route Optimizer
`Python` &nbsp;|&nbsp; `OR-Tools` &nbsp;|&nbsp; `FastAPI` &nbsp;|&nbsp; `React`

Google OR-Tools constraint solver that takes pickup points, truck capacities, and time windows and returns the lowest-cost valid route assignment. React map interface lets dispatchers move stops and watch the optimizer replan in under a second.
